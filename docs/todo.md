## 분석 결과 및 개선 방향

### 현재 상태
- 관리자 대시보드는 상단 드롭다운 중심 구조이며, 메뉴 수가 증가할수록 탐색 경로가 길어집니다.
- 대시보드의 최근 활동은 초기 HTML 더미 데이터와 JavaScript 실패 시 더미 데이터가 혼재되어 실제 운영 상태와 구분이 어렵습니다.
- 서버는 Express 단일 파일에서 라우트, DB 초기화, WebSocket 처리를 함께 담당해 기능 증가 시 유지보수 비용이 커질 수 있습니다.

### 개선 방향
- 구글 클라우드 콘솔과 유사하게 상단 앱 바, 검색 영역, 좌측 사이드바, 본문 카드 영역으로 역할을 분리합니다.
- 대시보드 숫자와 최근 활동은 서버 API에서 SQLite 조회 결과를 받아 표시합니다.
- Node.js 특성상 비동기 I/O를 활용해 통계 조회를 병렬 처리하고, 라우트와 DB 접근 코드는 후속 작업에서 모듈화합니다.

- **글로벌 설치 금지**: 모든 패키지는 로컬 프로젝트 내에서만 설치해야 함 (Node.js, Python, npm 패키지 등)
- **독립적인 환경**: 프로젝트는 자체 포함된 의존성만 사용해야 함
- **서버 구성**: 모든 서버 구성은 로컬 환경에서 동작해야 함
