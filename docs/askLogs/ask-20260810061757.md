# 작업 이력: xvideos.com 미디어 다운로드 매니저를 전용 팝업 창으로 분리 (ask-20260810061757)

## 요청
- "xvideos.com 미디어 목록 하게 되면 패널 아래로 주르륵 나오는데 창 범위를 벗어난다. 오픈 창으로 새롭게 나오던지 아니면 브라우저에 블랭크 가상 페이지를 만들고 거기서 출력하고 진행 버튼을 만들던지 해야지 패널 안으로 리스트가 나오면 화면이 좁아서 안 된다."

## 확정된 결괏값 (사용자 승인)
- 사이드바의 xvideos 그룹은 **"다운로드 매니저 열기" 버튼만** 남기고, 목록·진행·초기화 UI는 **전용 팝업 창(`chrome.windows.create`, type: "popup", 900×760)**으로 분리한다.
- 매니저 창은 대상 xvideos 탭(`?tabId=`)을 쿼리로 전달받아 `requestCollectXvideosMediaFromTab(tabId)`로 목록을 생성하고, 오프스크린 기존 파이프라인(`mediaAckWaiters` 60초 / `storageLocationWaiter` 15초)을 무수정 재사용한다.

## 처리 단계
1. `plugins/basic-plugin/vite.config.ts`: `rollupOptions.input`에 `xvideosManager: resolve(__dirname, "xvideos-manager.html")` 엔트리 추가(기존 sidepanel/offscreen/background/content 유지 → 엔트리 5종).
2. `plugins/basic-plugin/xvideos-manager.html` 신규: root div + Noto Sans CDN + `./src/xvideosManager.tsx` 로드.
3. `plugins/basic-plugin/src/hooks/useXvideosDownloadManager.ts` 신규: 모듈 함수 `extFromUrl`/`buildXvideosTxtContent`(usePopupState에서 이관) + `useXvideosDownloadManager()` 훅 — state(`downloadList`/`isRunning`/`pageUrl`/`storageDir`/`relDir`/`statusMessage`/`logs`), `addLog`(200건 상한), `buildList(tabId)`(목록 생성+중복 제거+저장 위치 조회), `startQueue()`(순차 진행, done/failed 집계), `reset()`, 타입 `XvideosManagerLog`/`XvideosManagerLogLevel`.
4. `plugins/basic-plugin/src/services/chromeService.ts`: `sendCommandToActiveTab`을 일반화한 `sendCommandToTab(tabId, command, payload)` 신설(콘텐츠 스크립트 미주입 탭은 content.js 주입 후 자동 재시도), 기존 active-tab 함수는 이를 호출하도록 리팩터, `requestCollectXvideosMediaFromTab(tabId)` 추가.
5. `plugins/basic-plugin/src/xvideosManager.tsx` 신규: React root(`StrictMode`+`createRoot`), `tabId` 쿼리 파싱(`chrome.tabs.get` 검증 → `chrome.tabs.query` 폴백) → initError 표시("xvideos.com 탭을 찾을 수 없습니다..."), 최초 자동 목록 생성(`builtOnce`).
6. `plugins/basic-plugin/src/components/XvideosManagerView.tsx` 신규: `XvideosManagerApi` 타입, 전체 레이아웃(헤더/제목+pageUrl+닫기, 저장 위치+상태 메시지, 2열 그리드 항목 목록, 버튼 3종(목록 생성/진행/초기화), 로그 터미널), `getDownloadStatusInfo`(대기/다운로드/완료/실패)/`DownloadListItem`/`LogLine` 컴포넌트. `popup.css`의 `btn-primary`/`btn-secondary`/`btn-mini` 토큰 재사용.
7. `plugins/basic-plugin/src/components/tabs/BasicTab.tsx`: `XvideosDownloadItem` import 제거, xvideos Props 6종 → `onOpenXvideosManager` 1종 교체, 카테고리 버튼 라벨을 "다운로드 매니저 열기"로 변경, 인라인 목록/진행/초기화/저장위치 JSX 제거.
8. `plugins/basic-plugin/src/hooks/usePopupState.ts`: xvideos state 5종 및 관련 import 제거, 기존 목록/진행 핸들러를 `handleOpenXvideosManager`(xvideos 탭 검색 → `chrome.windows.create` 팝업)로 교체, return 객체 반영.
9. `plugins/basic-plugin/src/sidepanel.tsx`/`popup.tsx`: BasicTab props를 `onOpenXvideosManager={handleOpenXvideosManager}`로 교체, `public/manifest.json`(basic·opera 양쪽)에 `"windows"` 권한 추가.
10. **opera-plugin 동기화**: 신규 3종(`useXvideosDownloadManager.ts`/`XvideosManagerView.tsx`/`xvideosManager.tsx`) + `xvideos-manager.html` + 수정 5종(`chromeService.ts`/`BasicTab.tsx`/`usePopupState.ts`/`sidepanel.tsx`/`popup.tsx`) + `vite.config.ts`를 헤더 주석(`plugins/opera-plugin/`) 교체로 복사(`background.ts`는 `chrome.sidePanel?.` 옵셔널 차이로 유지).
11. **문서 마감**: R-00440 §2.3(매니저 팝업 창 UI 규격 신설), R-00430 §5.4(목록 이관·`requestCollectXvideosMediaFromTab` 반영) 및 §6, R-00420 §4.5(주체 사이드바→매니저 창), R-00450(엔트리 4→5), askLog 신규, todo.md/history.md 반영.
