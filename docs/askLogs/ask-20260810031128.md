# 작업 이력: 이미지 수집 3그룹 정렬 개선 — 전체 추출·lazy 대응·중복 제거·www 루트 도메인 저장 (ask-20260810031128)

## 요청
- "플러그인에 이미지 수집 하위에 버튼을 3개를 둘 것이다: ① 일반 이미지 수집 ② xchina.co — 일반/앨범/표지/정보 ③ xvideos.com — 일반/정보."
- "일반 이미지 수집은 현재 열려있는 화면 렌더링이 되어있는 실제 DOM 요소들의 이미지를 전부 산출 후 다운로드해서 서버로 보내고, 서버는 기본 저장 경로에 각 도메인별로(일반은 normal) `/` 디렉토리 구분해서 저장."

## 확정된 상세 규격 (사용자 협의)
- 이미지 상한: `MAX_IMAGE_COLLECT_COUNT` 50 → **500**
- 사이트 버튼 노출: **항상 3그룹 표시**(일반 / xchina.co / xvideos.com), 비매칭 사이트 그룹은 `disabled` + "다른 도메인" 배지
- 중복 URL: **Set 기반 제거** 적용
- lazy 로드: `data-src/data-original/data-lazy-src/data-url/data-lazy` 폴백 적용
- 도메인 저장 폴더: **`www.` 제거한 루트 도메인으로 통일** (`www.xchina.co` → `images/xchina.co/normal/`), 기존 `www.` 폴더는 이관 없이 유지

## 처리 단계
1. `content.ts`: `MAX_IMAGE_COLLECT_COUNT` 50→500. 신규 `resolveImageSource()` — `currentSrc → src → data-src/data-original/data-lazy-src/data-url/data-lazy` 순 폴백. `collectAndSendImages()` — 렌더링 DOM `img` 전부 취합 후 중복 URL `Set` 제거 + 상한 초과 시 중단, 대상 구조 `{ img, src }`로 변경해 루프에서 해석된 src 재사용.
2. `BasicTab.tsx`: 사이트 전용 그리드를 `matchedSite` 조건부 → `Object.entries(SITE_IMAGE_BUTTONS)` 항상 렌더링. 각 그룹에 `현재 도메인`/`다른 도메인` 배지, 비매칭 그룹 버튼은 `disabled` + title 안내("~ 페이지에서만 사용할 수 있습니다").
3. `server/src/index.ts`: 신규 `normalizeRootDomain()` — `www.` 접두사 제거(그 외 서브도메인 유지). CRAWL_IMAGE/일반 도메인 추출(`targetUrl`/`pageUrl` hostname)에 적용해 저장 폴더와 crawl_logs domain을 루트 도메인으로 통일.
4. **opera-plugin 동기화**: 변경 2종(content.ts, BasicTab.tsx) 복사 + 헤더 교체.
5. **문서**: R-00208 §2.1(카테고리 하위 폴더·info 저장·루트 도메인 통일 규격), R-00430 §5.3(500 상한/lazy/중복 제거/3그룹 배지/www 정규화) + §6 체크리스트 3건 추가.
6. **검증**: 양 플러그인 빌드 + 서버 빌드(tsc) + pm2 재시작 online.
