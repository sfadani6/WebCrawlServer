# 작업 이력: 오페라 플러그인 액션 실행 — "xvideos 페이징 액션" 도움말 레이어 팝업 분리 + 인라인 설명 제거 (ask-20260822185248)

## 요청 (사용자 지시 원문)
- 오페라 플러그인에서 액션 실행 → xvideos 페이징 액션 이 버튼의 옆에 도움말을 넣을 것.
- 텍스트 부분들은 사라져야 한다(공간 낭비). 버튼 옆 도움말 아이콘 클릭 시 레이어 팝업으로 상세 도움말 표출.
- 대상 설명 문단: ① 섹션 안내("사이트별 페이지 자동화 액션 모듈을 실행하는 영역입니다...") ② 액션 카드 하단 설명("페이지 수를 감지해 1페이지씩 순차 이동합니다...").

## 확정 사항
- 장문 설명은 카드에 인라인 노출하지 않고 "?" 원형 아이콘 버튼(`btn-help-round`) + 공용 레이어 팝업(`ActionHelpModal.tsx`)으로 이관한다.
- 폰트 아이콘 배제 원칙(R-00440 §1.3) 유지 — 트리거는 텍스트 "?", 닫기는 "✕" 유니코드.
- basic-plugin 우선 수정 후 opera-plugin 동기화(헤더 경로만 교체, diff 0 확인).

## 처리 단계
1. `components/ActionHelpModal.tsx` 신규(basic): 오버레이(`fixed inset-0 z-[1000] bg-black/70`) + 중앙 다이얼로그(max-w 340px/max-h 70vh 스크롤), `ActionHelpSection { heading, paragraphs[] }` 목록 렌더링, 닫기 경로 3종(✕ 버튼/배경 클릭 stopPropagation/ESC keydown 리스너), 접근성 속성(role=dialog/aria-modal/aria-label) 적용.
2. `BasicTab.tsx`(basic): 섹션 안내 `<p>` 및 카드 하단 설명 `<p>` 삭제 → `XV_BEST_OF_RED_ACTION_HELP` 상수(액션 실행/동작 방식/수집 조건/저장 경로/실행 조건 5개 섹션)로 재구성해 팝업 본문에 사용. 실행 버튼 행을 `flex items-stretch gap-2`로 개편(실행 버튼 `flex-1` + "?" 버튼 `shrink-0`), `isActionHelpOpen` 상태 추가.
3. `popup.css`(basic): `.btn-help-round` 토큰 신설(원형, min-width 36px, sky 계열 글자, hover 강조) — `.btn-mini.on` 직후 배치.
4. opera-plugin 동기화: popup.css/BasicTab.tsx/ActionHelpModal.tsx 3종 복사 후 헤더 경로 교체, 정규화 diff 0 확인.
5. 검증: tsc --noEmit basic/opera 통과, 양 플러그인 vite 빌드 성공(sidepanel.js 갱신), ESLint 신규 오류 0건, dist에 `btn-help-round` 포함 확인.
