## 1. 브라우저 플러그인 분석 및 도출된 5대 개선 영역

### 1.1 Manifest V3 Service Worker 수명주기 & 연결 신뢰성
- Service Worker 휴면(Idle Shutdown) 대응 `chrome.alarms` 킵얼라이브 적용.
- 지수 백오프(Exponential Backoff) 기반 재연결 및 무한 서버 요청 방지 서킷 브레이커 적용.
- 오프라인 메시지 큐(`chrome.storage.local`) 보관 및 재연결 후 순차 재전송.

### 1.2 콘텐츠 스크립트(contentScript.js) DOM 스크래핑 & 스크립트 실행 오류 개선
- 동적 DOM 요소, Cross-origin iFrame 및 Shadow DOM 타임아웃 예외 핸들링 보강.
- SPA 페이지 이동(`History API`) 감지 및 Content Script 중복 주입 충돌 차단.

### 1.3 플러그인 팝업 UI (popup/popup.html, popup.js) UI/UX 고도화
- 미승인 접속 요청 상태(`requestId`) 인라인 뱃지 및 승인 대기 안내 표시.
- 최근 20개 MCP 패킷 인라인 JSON 뷰어, 자동 스크롤 및 단일 클릭 복사 버튼 추가.
- 팝업 내 현 설정 서버 URL 즉시 확인 및 재연결 숏컷 제공.

### 1.4 옵션 페이지 (options/options.html, options.js) UI/UX 개선
- WebSocket 서버 URL `ws://`/`wss://` 라이브 검증 및 연결 테스트(Ping) 버튼 추가.
- 저장된 보안 토큰 마스킹(`••••••••`) 및 토큰 재발행/초기화 모달 인터랙션.
- Admin UI 디자인 가이드(Tailwind CSS)와 플러그인 UI 폰트 및 테마 스타일 통일.

### 1.5 다중 탭 제어 & 대용량 패킷 분할 전송
- 닫힌 탭 이벤트(`chrome.tabs.onRemoved`) 감지 시 메모리 자원 가비지 컬렉션.
- 대용량 HTML/이미지 데이터 전송 시 소켓 메세지 분할(Chunking) 전송 및 백엔드 재조합.
