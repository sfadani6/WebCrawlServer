# 작업 이력: 오페라 전용 플러그인(`plugins/opera-plugin`) 신설 (ask-20260809100542)

## 요청
- "오페라 브라우져에서는 sidebar_action 이라고 해야 한다고 하네 / Permission 'sidePanel' is unknown. 이라고 하고 사이드 패널이 안나와"
- "plugins\basic-plugin 일반 크롬 지원으로 기본 개발로 하고 / plugins\opera-plugin 오페라 브라우져 지원으로 하고 오페라 특수만 변경 하고 기능은 basic-plugin 기능 그대로하고"

## 원인 분석
- `plugins/basic-plugin/public/manifest.json`은 크롬 표준 `sidePanel` permission + `side_panel` 키 사용 → 오페라가 `sidePanel` permission을 인식하지 못해 `Permission 'sidePanel' is unknown` 오류로 로드/사이드바 실패.
- 오페라 사이드바는 별도 권한 없이 `sidebar_action` 매니페스트 키(`default_panel` 필수)로 동작하며 크롬 `side_panel` 키와 호환되지 않아 단일 manifest 동시 지원 불가능.

## 처리 단계
1. `plugins/opera-plugin` 신설: `plugins/basic-plugin` 전체 소스 사본(`public/`, `src/`, HTML 엔트리, `vite.config.ts`, `tsconfig.json`, `.npmrc`) — node_modules/dist 제외.
2. 오페라 특수 변경: manifest.json(`sidePanel` permission·`side_panel` 키 제거 → `sidebar_action` 키 추가, name/description 오페라 명시), `background.ts`(`chrome.sidePanel?.setPanelBehavior` 옵셔널 가드), `package.json`(name=opera-plugin), 소스 헤더 경로 주석 20개 + vite.config.ts 일괄 교체.
3. 루트 `package.json`: `workspaces`에 `plugins/opera-plugin` 추가, `plugin:opera:dev` 신설, `build:all`에 opera 빌드 포함.
4. 문서: `R-00460`(§1.4 오페라 지원 규정, §6 오페라 전용 매니페스트 명세, §7 검증 절차), `R-00410`(§2.1 병행 구조), `ADR-006` 신규.
5. 이력: docs/todo.history.md + docs/askLogs/ask-20260809100542.md + docs/ask.md 초기화.

- `npm run build --workspace=basic-plugin` 성공 → 크롬 빌드 정상 유지.
