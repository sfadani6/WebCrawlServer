# 작업 이력: 오페라 플러그인 `sidePanel` 퍼미션 오류 재발 수정 — `sidebar_action` manifest 회귀 복구 + 재발 방지 규정 (ask-20260811011205)

## 요청 (사용자 지시 원문)
- "오페라 브라우져에 퍼미션 오류 났어 / Permission 'sidePanel' is unknown."
- "오페라 브라우져에서는 'sidePanel' 퍼미션 대신 'sidebar' 퍼미션을 사용해야 합니다. 따라서 매니페스트 파일에서 'sidePanel'을 'sidebar'로 변경하면 퍼미션 오류가 해결될 것입니다." (사용자가 받은 AI 제안 문구)

## 원인 진단
- **회귀**: ask-20260809100542에서 오페라 전용 manifest(`sidebar_action`, `sidePanel` 제거)로 정상화했으나, 이후 동기화 과정(이미지/영상 수집)에서 `basic-plugin`의 manifest를 **통째로 복사**하면서 `sidePanel` 퍼미션 + `side_panel` 키가 오페라 manifest에 다시 유입됨 → `Permission 'sidePanel' is unknown` 재발.
- **사용자 제안("sidebar" 퍼미션)은 부정확**: Opera 공식 "Permissions Declarations"에 `sidebar` 퍼미션은 존재하지 않음. 오페라 사이드바는 **별도 권한 없이 `sidebar_action` 매니페스트 키**(`default_panel` 필수)로만 동작(Opera Sidebar Action API, W3C 권한 표: Opera → `sidebar_action` → permission `-`). `sidebar`를 추가하면 동일한 "unknown permission" 오류가 발생하므로 추가하지 않음.

## 처리 단계
1. `plugins/opera-plugin/public/manifest.json` 수정:
   - `permissions`에서 `"sidePanel"` 제거(나머지 35종 유지, `windows` 포함 — 다운로드 매니저 `chrome.windows.create` 사용).
   - `"side_panel": { "default_path": ... }` → `"sidebar_action": { "default_title": "WebCrawlServer 수집 대시보드", "default_panel": "sidepanel.html", "default_icon": {16/32/48/128} }` 교체.
   - name → `"오페라 검증용 수집 플러그인"`, description → 오페라 명시 문구로 회귀 복구.
   - `content_scripts run_at: "document_start"`(네트워크 감시 개선)는 유지.
2. `background.ts`: 변경 없음 — `chrome.sidePanel?.setPanelBehavior` 옵셔널 가드 유지(오페라에서 `chrome.sidePanel` undefined → no-op).
3. 검증: `npm run build`(opera-plugin, 56 모듈) → `dist/manifest.json`에서 `sidebar_action` 존재, `sidePanel` permission/`side_panel` 키 부재, name 오페라 문구, run_at document_start 확인.
4. 문서: R-00460 §6.4 "동기화 시 재발 방지 주의" 신설(manifest 통째 복사 금지 + 3대 유지 항목 + 빌드 후 dist 검증), askLog 신규(ask-20260811011205), ask.md 초기화.

## 확인된 동작 규칙 (검증 대상)
- 오페라 `opera://extensions`에서 `plugins/opera-plugin/dist` 로드 시 `Permission 'sidePanel' is unknown` 오류가 사라지고 확장 프로그램이 정상 로드된다.
- 툴바 아이콘(또는 사이드바 버튼 목록) 클릭 시 `default_panel`(`sidepanel.html`)이 사이드바로 표시된다.
- 이후 basic-plugin → opera-plugin 동기화 시 manifest는 R-00460 §6.2 기준으로 diff 반영하며 §6.4 규정을 준수한다.
