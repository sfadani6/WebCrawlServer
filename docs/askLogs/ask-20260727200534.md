## 요청 내용
사용자가 `/plugins` 화면에서 연결 방법을 확인할 수 있는 채팅창 또는 안내 화면이 보이지 않아 플러그인을 어떻게 연결해야 하는지 알 수 없다고 보고하였다.

## 수행된 작업
- `server/admin-ui/src/components/PluginsPage.jsx`에 항상 보이는 `ConnectionGuide` 컴포넌트를 추가하였다.
- 연결 도우미에는 WebSocket URL 복사 버튼, 승인 대기/승인됨 카운트, 실제 연결 절차 4단계를 표시하였다.
- 기존 서버 연결 정보 문구와 빈 승인 대기 메시지를 연결 도우미 기준으로 수정하였다.

## 변경 이유
- 이전 수정에서 혼선을 유발하던 미사용 채팅 UI를 제거했지만, 연결 절차를 대체 안내로 충분히 노출하지 못했다.
- 플러그인 연결은 관리자 페이지에서 채팅 메시지를 보내는 방식이 아니라 확장 프로그램이 먼저 연결 요청을 만들고 관리자가 승인하는 방식이므로, 이 절차를 화면에 고정 표시해야 한다.

## 검증
- `node --check`로 서버 및 플러그인 JavaScript 파일 구문을 확인하였다.
- `git diff --check`로 공백 오류를 확인하였다.
- `npm --prefix server/admin-ui run build`는 관리자 UI 로컬 의존성의 `vite` 실행 파일이 없어 실패하였다.
