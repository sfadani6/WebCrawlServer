## 1. 변경 내역

### 1.1 서버 모니터링 및 API 확장
- `server/monitor/connectionManager.js`:
  - 실시간 메시지 흐름 버퍼(`messageFlowLog`, 최대 100개 저장) 및 누적 통계(`totalInboundMessages`, `totalOutboundMessages`, `totalInboundBytes`, `totalOutboundBytes`) 관리 기능 구현
  - `recordMessageFlow`, `getRecentMessageFlow` 메서드 추가
  - WebSocket 메시지 수신, 연결 해제, 오류 발생 시 실시간 이벤트 자동 기록
- `server/routes/admin.js`:
  - GET `/admin/api/connections/flow` REST API 엔드포인트 구현 (최근 메시지 흐름 로그 반환)

### 1.2 관리자 UI 대시보드 개발
- `server/admin-ui/src/components/WebSocketDashboard.jsx` (신규 생성):
  - 실시간 WebSocket 활성 세션 수, 수신/발신 메시지 건수 및 누적 바이트, 서버 자원(메모리, CPU) 메트릭 시각화
  - 최근 실시간 패킷 트래픽 추이 타임라인 그래프 (수신/발신 구분)
  - 활성 소켓 노드 목록 및 세션 개별 강제 종료 컨트롤
  - 메시지 이벤트 스트림 테이블 (방향, 이벤트 타입, 소켓 ID, IP, 바이트 크기, 패이로드 요약, 발생 시각)
  - 이벤트 방향(IN/OUT/ALL) 필터링, 타입/내용 키워드 검색 및 선택 시 상세 JSON 페이로드 모달
  - 테스트 핑/메시지 수동 발송 폼
- `server/admin-ui/src/components/ConnectionPage.jsx`:
  - 상단 탭 네비게이션("⚡ 실시간 WebSocket 대시보드" / "📡 클라이언트 연결 목록")을 추가하여 대시보드 컴포넌트 연동

- 서버와 브라우저 플러그인/클라이언트 간에 주고받는 WebSocket MCP 패킷 흐름 및 상태 변화를 관리자 화면에서 실시간으로 한눈에 파악하고 디버깅할 수 있도록 시각화 기능을 강화하였습니다.
