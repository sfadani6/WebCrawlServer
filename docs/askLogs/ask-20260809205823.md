# 작업 이력: 기본 탭 개편 + 터미널 공통화 + URL 자동 갱신 (ask-20260809205823)

## 요청
- "현재 디버깅에 있는 터미널을 모든 페이지 하단에 넣고 하단 맨 아래 위치하게 해줘. 스크롤도 생기고 외곽 아웃라인도 디자인에 맞게 개선해줘"
- "기본 탭 구성: DOM(html) 전송(전체/요소선택/프레임), 이미지 수집, 액션 실행(미개발)"
  - 전체: 현재 페이지 전체를 서버로 전송
  - 요소선택: 마우스 오버 시 요소 외곽이 파란색 테두리 → 클릭하면 해당 위치에 "전송" 버튼 → 그 요소 데이터만 전송
  - 프레임: iframe 존재 시 선택 전송, 미존재 시 버튼 비활성화
  - 이미지 수집: 현재 페이지 이미지 추출해 서버 전송, 서버는 지정 폴더에 저장
  - 액션 실행: 미개발 상태 유지 (설계 후 구현 예정)
- "페이지 URL이 변화되면 [현재 페이지]도 자동으로 바뀌어야 하는데 현재 활성화된 탭을 계속 감시하지 못하는 것 같다"

## 확정된 상세 규격 (사용자 협의)
- 이미지 저장 규격: `<data_path>/images/<domain>/<timestamp>-<index>.<ext>` 전용 폴더 (원장 .bin 규격과 분리)
- 크로스 오리진 이미지: fetch→base64 실패 시 src URL만 전송해 서버가 참조 파일로 보관 (스킵하지 않음)
- 요소 선택 전송 형식: outerHTML 전체를 CRAWL_PARTIAL로 전송

## 처리 단계
1. `types/index.ts`: CrawlImagePayload, CrawlElementPayload 추가
2. `content.ts`: 요소 선택 모드(파란 테두리 outline 3px #3b82f6, 클릭 시 전송 플로팅 버튼, outerHTML → CRAWL_PARTIAL, ESC 종료, ELEMENT_PICKER_ENDED 통지), GET_FRAME_INFO/COLLECT_FRAME_DOM(크로스 오리진 src 참조), COLLECT_IMAGES(fetch→base64 성공 / URL 참조 실패, 최대 50개)
3. `chromeService.ts`: 공통 헬퍼 sendCommandToActiveTab(미주입 탭 주입 재시도) + requestStart/StopElementPicker/requestFrameInfo/requestCollectFrameDom/requestCollectImages
4. `TerminalConsole.tsx` 신설: 기존 DebugTab 터미널을 공통 컴포넌트로 분리, 하늘색 아웃라인+개선 스크롤바
5. `BasicTab.tsx` 개편: DOM 전송 아코디언(라디오 전체/요소선택/프레임, 프레임 미존재 비활성화), 이미지 수집, 액션 실행(disabled), URL 카드
6. `usePopupState.ts`: 요소/프레임/이미지 상태·핸들러 추가, chrome.tabs.onActivated/onUpdated 리스너로 활성 탭 URL+iframe 자동 감시
7. `sidepanel.tsx`/`popup.tsx`: 터미널을 모든 탭 하단 공통 배치, `popup.css` 섹션 카드/라디오/터미널 스타일
8. 서버: `fileStorageService.saveCrawledImage` (images/<domain>/<timestamp>-<index>.<ext>, 실패 .url 참조), `index.ts` CRAWL_IMAGE 분기(insertCrawlLog action=CRAWL_IMAGE + updateCrawlLogFile, pageUrl 도메인 분류)
9. opera-plugin 동기화: 변경 10개 파일 복사 + 헤더 경로 주석 plugins/opera-plugin 교체
