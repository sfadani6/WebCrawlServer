# 작업 이력: 플러그인 UI/스타일 정비 — 폰트 아이콘 제거·터미널·이미지 수집 정돈·버튼 가시성 (ask-20260810033437)

## 요청
- "플러그인에 폰트 아이콘 등은 제거해 줬으면 좋겠다. 터미널 출력 부분·입력 부분, 이미지 수집 부분들의 스타일이 정돈되어야 한다."
- "버튼인데 흰글씨에 흰바탕이면 보이지도 않는다."
- "일관적인 스타일, 가급적 아이콘 배제."
- "플러그인의 UI 디자인을 보고 개선점을 찾아라. 특히 스타일 부분, 버튼들의 색과 폰트 색 등이 엉망인 것 같다."

## 확정된 상세 규격 (사용자 협의)
- 아이콘 제거 범위: Material Symbols 폰트 아이콘 **전부 제거**(22곳), 아코디언 열림/닫힘 표시만 유니코드 `▼`/`▶` 허용
- 버튼 색상 체계: **파랑 단일화 + 앰버 유지** — 모든 실행 버튼 파랑 그라데이션 통일, `요소 선택` 모드만 앰버(기능 구분), 설정탭 `#1A73E8` 제거
- 버튼 가시성: 비활성 상태를 `opacity` 대신 **명시적 고대비 색상**으로 표시

## 처리 단계
1. `popup.css`: Material Symbols `@import` 제거(google fonts CDN). 공통 버튼 토큰 신설 — `btn-primary`(파랑 그라데이션 + 비활성 명시 고대비 `#1e293b`/`#334155`/`#94a3b8`), `btn-accent`(앰버), `btn-secondary`(보조 그리드, 비활성 `#64748b`), `btn-mini`(소형 다크, ON 에메랄드). `terminal-log-line`/`terminal-log-time`(타임스탬프 계층 + 호버) 및 `terminal-input`(박스형 + sky 포커스 링) 스타일 추가. 기존 `.send-button`/`.send-button-accent` 제거.
2. `Header.tsx`: 로고 아이콘 → 파랑 도트 배지.
3. `TerminalConsole.tsx`: `terminal` 아이콘 제거, 헤더 버튼 `btn-mini` 통일, 로그 행 타임스탬프/본문 분리 구조 + 호버, 입력줄 박스형(`>` 프롬프트 + 포커스 링).
4. `BasicTab.tsx`: 아이콘 16곳 제거(data_object/image/play_circle/link/web/ads_click/web_stories/photo_library/public/카테고리 4종/스피너). 아코디언 `▼/▶` 유니코드 전환. 실행 버튼 `btn-primary`(+요소선택 시 `btn-accent`), 사이트 카테고리 `btn-secondary` 통일, `getSendButtonIcon()` 제거.
5. `DebugTab.tsx`(send), `InfoTab.tsx`(browser_updated/memory), `SettingsTab.tsx`(settings + `#1A73E8`→`btn-primary`, input 포커스 `#1A73E8`→`#38bdf8`) 아이콘/색상 통일.
6. HTML 3종(popup.html, sidepanel.html, public/sidepanel.html): Material Symbols CDN `<link>` 제거.
7. **opera-plugin 동기화**: 변경 10종 복사 + 헤더 주석 교체.
8. **문서**: R-00440 §1.3 아이콘 시스템→아이콘 배제 원칙, §1.4 버튼 색상 체계 신설, §2 레이아웃 도식·§4.2 진행 표시 규정 갱신.
