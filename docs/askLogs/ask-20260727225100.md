## 1. 분석 결과 및 주요 개선 방향

### 1.1 로컬 개발 및 실행 환경 편의성 개선
- 개인 노트북 단일 사용자 환경 특성을 고려하여 매번 반복되는 Basic Auth 로그인 절차를 단축할 수 있는 `.env` 설정 기반 `LOCAL_SINGLE_USER_MODE` 자동 바이패스 옵션 구상.
- 단일 명령어로 백엔드 및 UI 개발 서버를 연동 구동할 수 있는 로컬 실행 스크립트 정리.
- 데이터 손실 방지를 위한 SQLite DB 스냅샷 원클릭 백업 및 복원 UI 보강.

### 1.2 수집 데이터 활용성 및 엑셀/CSV 추출 강화
- 크롤러 모듈 및 테이블 브라우저(`SpreadsheetView.jsx`)에서 수집 데이터를 로컬 `.csv`, `.json`, `.xlsx` 파일로 즉시 다운로드하는 단일 클릭 내보내기 기능 강화.
- 중복 URL 및 수집 데이터 자동 필터링 뷰 제공.

### 1.3 노트북 자원 최적화 및 로컬 알림
- 배터리 및 CPU 리소스 관리를 위한 크롤러/스케줄러 유휴 폴링 제어 및 SQLite DB 자동 정리(`VACUUM`) 태스크 추가.
- 작업 완료/오류 발생 시 OS 데스크톱/브라우저 알림 연동.

### 1.4 플러그인 로컬 연동 및 모니터링 디버깅
- `localhost` 환경에서 브라우저 플러그인과 로컬 서버 간 자동 탐색 및 간편 토큰 발급.
- `WebSocketDashboard.jsx` 내 메시지 흐름 패킷 데이터 JSON 저장 기능.
