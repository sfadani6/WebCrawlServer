데이터베이스 -> 데이터 베이스 생성 이있고 
각 데이터 베이스 옆 테이블 관리 앞에 삭제도 있어야되.
: main.db는 기초 베이스라 삭제하면 안되.
테이블 관리에 각 테이블 셀이 그리드로 나오는데 오늘쪽 끝에 행 삭제 버튼이있어야되
그리고 각 행의 셀을 클릭하면 값을 입력되게 변경할수있어야되.
입력이 다 끝난 후  행 우측에 저장 버튼이있어야되.
테이블 목록에 테이블 삭제도 있어야되
그리고 테이블 목록에 테이블 생성이있는데 
테이블 생성 버튼 누르면 레이어창이 나오고 
어떤 컬럼을 추가할건지 그 컬럼 타입이 무엇인지 그리고 컬럼의 제약조건이 무엇인지 선택할수있어야되
그리고 생성 누르면 
테이블 목록이 갱신되어야되

설정 - 이부분은 main.db의 config 테이블에 저장되는거고 서버가 기동후 이부분 데이터를 참조하거나 다른 앱들이 참조하게되는거야 
필드 구성 : 속성, 문자열 필드, 문자열필드 , 메모, 등록날자
이부분도 그리드 형식으로 하면좋겠다 
이 필드의 목적 예시 : 속성 : 브라우져 , 문자열 필드 : 브라우져 실행 위치 , 문자열 필드 : 브라우져 실행 인자 , 메모 : 브라우져 설명 , 등록날자 : 20260726
이런식이야 
속성 : 브라우져 란 텍스트로 브라우져가 아니라
main.db 에서 configattr 테이블에서 정의한 속성이야 
configattr 테이블의 id와 일치하는 행을 찾아서 속성에 그 정의된 텍스트를 가져와서 표시하면되. 
그리고 configattr 테이블 필드는 
idx, 이름, 설명 , 등록날자

config 테이블은 idx, 속성, 문자열필드1, 문자열필드2, 메모, 등록날자  
idx가 main.db 의 configattr 테이블의 idx 와 일치하는 행을 찾아서 
속성에 그 정의된 텍스트를 가져와서 표시하면되. 

그리고 행 삭제 버튼이있어야되
그리고 각 행의 셀을 클릭하면 값을 입력되게 변경할수있어야되.
입력이 다 끝난 후  행 우측에 저장 버튼이있어야되.

설정 에 테이블 삭제도 있어야되
