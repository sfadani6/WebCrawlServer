# 작업 이력: xvideos best-of-red 자동 페이징 이동 수집 (ask-20260810163514)

## 요청
- `https://www.xvideos.com/best-of-red/<월>/` 주소로 이동해서 액션 실행 버튼을 누르면 **0페이지부터 16페이지까지 자동으로 이동하며 각 페이지의 비디오 메타를 수집**한다. (사용자가 ask.md에 붙여 넣은 best-of-red 페이지 DOM 원문 기반)

## 확정된 결괏값
- 사이드바/팝업 xvideos 그룹에 **"best-of-red 자동 이동"** 버튼을 추가한다.
- 버튼 클릭 시 현재 best-of-red 페이지부터 페이지네이션(`.pagination a[data-page]`)의 **마지막 페이지까지 탭이 자동 이동**하며, 각 페이지의 비디오 메타(`.thumb-block` 비디오 블록)를 기존 `collectXvideosMediaEntries()` 파싱 규칙으로 수집해 서버로 누적 전송한다.
- URL 직접 이동 방식으로, 페이지 이동 시 콘텐츠 스크립트 컨텍스트 파괴·재주입 문제는 `sessionStorage` 세션으로 극복한다.

## 처리 단계
1. `plugins/basic-plugin/src/content.ts`:
   - 상수/타입: `XV_BEST_OF_RED_SESSION_KEY`("xvBofR")/`XV_BEST_OF_RED_DELAY_MS`(800ms)/`XV_BEST_OF_RED_BASE_RE` + `XvBestOfRedState { basePath, pageIndex, maxPage, startedAt }`.
   - `save/clearXvBestOfRedSession`, `buildXvBestOfRedPageUrl`(0=베이스 URL, N=`베이스/N`), `parseXvBestOfRedUrl`(후행 슬래시 유무 무관·`/N` 페이지 인덱스 캡처), `detectXvBestOfRedMaxPage`(data-page 연속 블록 최대값), `sendXvBestOfRedPagePacket`(CRAWL_PARTIAL json, `.catch` 가드), `runXvBestOfRedEngine`(수집→전송→다음 페이지 이동), `maybeResumeXvBestOfRed`(재주입 시 세션 자동 재개·예상 URL 불일치 시 세션 정리), `startXvBestOfRed`(URL 검증→세션 초기화→엔진 실행, `{ success, message }` 동기 응답).
   - 메시지 리스너 [7-2] 분기 `START_XVIDEOS_BEST_OF_RED` 추가(비동기 대기 없이 즉시 응답), 파일 최하단에 `maybeResumeXvBestOfRed()` 호출.
   - `collectXvideosMediaEntries()` 셀렉터를 `.thumb-block` → `.thumb-block:not(.thumb-ad)`로 보강(광고 블록 제외).
2. `plugins/basic-plugin/src/services/chromeService.ts`: `requestStartXvideosBestOfRed()` — `sendCommandToActiveTab("START_XVIDEOS_BEST_OF_RED")` 래퍼.
3. `plugins/basic-plugin/src/hooks/usePopupState.ts`: `handleRunXvBestOfRed()`(상태 메시지 + 터미널 로그 + 요청 결과 반영) + return 반영.
4. `plugins/basic-plugin/src/components/tabs/BasicTab.tsx`: `onRunXvBestOfRed` prop 추가, `isXvBestOfRedUrl()`(경로 `/best-of-red/`) 판별, xvideos 그룹 하단에 best-of-red 자동 이동 버튼(best-of-red 페이지에서만 활성화).
5. `plugins/basic-plugin/src/popup.tsx`/`src/sidepanel.tsx`: `onRunXvBestOfRed` props 배선.
6. **opera-plugin 동기화**: content.ts/chromeService.ts/usePopupState.ts/BasicTab.tsx/popup.tsx/sidepanel.tsx 6종(헤더 경로만 교체).
7. 문서: R-00430 §5.5(자동 이동 액션 규격)+§6, R-00480 §3.1(시나리오), R-00440 §2.3(버튼 구성), R-00420 §4.5(명령 규격), askLog 신규.
