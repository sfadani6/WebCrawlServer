## 수행된 작업

### 1. 관리자 페이지 현재 상태 분석
- **변경 내용**: 상단 드롭다운 중심 구조, 더미 데이터 표시, 단일 서버 파일 구조를 개선 대상으로 정리했습니다.
- **파일 위치**: docs/todo.md
- **기능**: 우선순위 작업과 개선 방향을 문서화했습니다.

### 2. 관리자 대시보드 레이아웃 개편
- **변경 내용**: 관리자 대시보드를 상단 앱 바, 검색 영역, 좌측 사이드바, 본문 지표 카드, 상태 패널, 최근 활동 테이블로 재구성했습니다.
- **파일 위치**: public/admin/index.html, public/admin/css/admin.css
- **기능**: 구글 클라우드 콘솔형 정보 구조를 적용했습니다.

### 3. Node.js API 개선
- **변경 내용**: `/api/stats`, `/api/activities` 조회 API를 추가하고 SQLite 조회를 Promise 기반 헬퍼로 분리했습니다.
- **파일 위치**: server/app.js
- **기능**: 대시보드가 더미 데이터 대신 서버 조회 결과를 사용할 수 있게 했습니다.
