## 1. 주석 작성 체크리스트

**반드시 포함:**
- [ ] 파일 최상단: 목적, 기능, 사용법
- [ ] 각 섹션 앞: 해당 섹션의 역할
- [ ] 함수: 함수명, 목적, 파라미터, 반환값
- [ ] 복잡한 로직: 단계별 근거(왜 이 방식을 선택했는지 포함)
- [ ] 정규표현식: 매칭 패턴 설명
- [ ] try/catch: 예상 오류 종류

**피해야 할 주석:**
- [ ] 코드 그대로 설명하는 자명한 주석 (예: `let x = 1; // x를 1로 설정`)
- [ ] 주관적 의견, 농담
- [ ] 삭제된 구식 코드를 주석으로 남기는 행위 (Git 히스토리로 대체)

## 2. 금지 사항
- 절대 경로 하드코딩 (상대 경로 또는 프로젝트 루트 기준 경로 변수 사용)
- 진행 상황 표시 없는 장시간 작업
- 조용한 오류 처리 (오류는 반드시 사용자/로그에 노출)
- 전역 상태의 무분별한 변경
- MCP 표준 명령어 집합과 충돌하는 임의 액션명 생성(`mcp.md` 참조)
- 근거 없는 추측에 기반한 API/DB/구조 생성(`AGENTS.md` 1.7 참조)
