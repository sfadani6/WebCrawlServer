다음은 AI에게 **Google Sheets처럼 직관적인 웹 기반 SQLite 테이블 관리 기능**을 구현하도록 지시하는 개발 지침서입니다.

# AI 개발 지침 - Google Sheets 수준의 웹 기반 SQLite 테이블 관리

# 목표

SQLite 데이터베이스를 웹 브라우저에서 매우 쉽고 빠르게 관리할 수 있는 인터페이스를 개발한다.

사용자는 SQL을 몰라도 마우스와 키보드만으로 대부분의 작업을 수행할 수 있어야 한다.

UI와 사용성은 **Google Sheets, Airtable, Notion Database** 수준을 목표로 하며, 데이터 편집 속도는 데스크톱 프로그램(DBeaver, TablePlus)과 유사한 수준을 제공해야 한다.

---

# 핵심 원칙

* SQL 작성 없이 데이터 수정 가능
* 클릭 한 번으로 셀 편집
* Excel/Google Sheets와 동일한 조작 방식
* 모든 작업은 가능한 한 즉시 반영
* 위험한 작업은 확인 후 실행
* 실행 취소(Undo) 및 다시 실행(Redo) 지원
* 대용량 데이터에서도 부드럽게 동작

# 개발 원칙

1. 모든 편집은 인라인(Inline Editing) 방식으로 구현한다.
2. 사용자는 SQL 없이 대부분의 작업을 수행할 수 있어야 한다.
3. 모든 변경 사항은 즉시 저장하되 오류 발생 시 자동 복원한다.
4. 모든 삭제 작업은 확인 절차와 실행 취소(Undo)를 지원한다.
5. UI는 Google Sheets 수준의 직관성과 반응성을 제공한다.
6. 모든 데이터 변경은 트랜잭션으로 처리하여 데이터 무결성을 보장한다.
7. 대용량 데이터 처리 시 메모리 사용을 최소화하고, 가상 스크롤과 지연 로딩을 적용한다.
8. 키보드 단축키와 마우스 조작을 모두 지원하여 생산성을 극대화한다.
9. AI는 위험한 SQL(DELETE, DROP, UPDATE 등)을 실행하기 전에 반드시 영향을 받는 데이터의 미리보기와 예상 변경 건수를 제공해야 한다.
10. 코드 구조는 컴포넌트 기반으로 설계하여 기능 추가와 유지보수가 쉽도록 구현한다.

이 지침을 기반으로 구현하면 **Google Sheets처럼 셀을 클릭하여 바로 수정하고, 우클릭으로 삭제·복사·붙여넣기·필터링·정렬을 수행하며, SQL을 거의 사용하지 않고도 SQLite를 편리하게 관리할 수 있는 웹 기반 데이터 관리 도구**를 개발할 수 있습니다.
