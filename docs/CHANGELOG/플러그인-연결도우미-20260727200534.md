# 플러그인 연결 도우미 표시 보강 - 20260727200534

## 변경 개요
`/plugins` 화면에서 사용자가 연결 절차를 바로 확인할 수 있도록 항상 표시되는 연결 도우미 패널을 추가하였다.

## 변경된 파일 목록
- `server/admin-ui/src/components/PluginsPage.jsx`
- `docs/CHANGELOG.md`
- `docs/askLogs/ask-20260727200534.md`
- `docs/todo.history.md`

## 파일별 상세 변경 내용

### server/admin-ui/src/components/PluginsPage.jsx
- `ConnectionGuide` 컴포넌트를 추가하였다.
- 연결 도우미에 WebSocket URL 복사 버튼을 추가하였다.
- 연결 도우미에 승인 대기/승인됨 카운트를 표시하였다.
- 연결 도우미에 확장 프로그램 옵션 열기, 서버 주소 저장, 연결 버튼 클릭, 승인 버튼 클릭의 4단계 절차를 표시하였다.
- 승인 대기 요청이 없을 때 표시되는 빈 상태 문구에 연결 요청 생성 방법을 추가하였다.

### 문서
- `docs/CHANGELOG.md`에 0.1.7 변경 이력을 추가하였다.
- `docs/askLogs/ask-20260727200534.md`에 작업 로그를 추가하였다.
- `docs/todo.history.md`에 처리 이력을 추가하였다.

## 변경 이유
이전 변경에서 미사용 채팅 UI를 제거한 뒤 연결 절차를 충분히 대체 안내하지 못해, 사용자가 플러그인을 어디서 어떻게 연결해야 하는지 확인하기 어려웠다.
