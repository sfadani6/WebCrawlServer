# 작업 이력: DB 관리 UX 개선 (긴 셀 미리보기 + 페이지네이션 기본값 configs + file_path 탐색기) (ask-20260809231120)

## 요청
- "DB관리에서 테이블 선택하면 rows가 출력되는데 log_message 같이 html이 통으로 들어간 것은 너무 길다. 출력 문자열 제한하고 더보기로 전체 log_message를 레이어 창으로 볼 수 있게. 레이어 창은 현재 브라우저 창 높이에 맞게 하고 스크롤도."
- "테이블 선택하면 몇 행씩 보는 기능이 없다. 기본 20개씩 페이징 처리. 기본 값은 server/configs.json에 디비관리 기본 rows 출력 행 개수를 지정하고 기초 환경설정으로 편입."
- "file_path 부분도 옆에 작은 버튼으로 파일 브라우저가 열리게. 파일까지는 프로그램 연결이 필요하니 디렉토리까지만, 디렉토리는 윈도우 파일 브라우저가 실행되게. 브라우저 내부 파일 브라우저 레이어로 처리하지 말고."

## 확정된 상세 규격 (사용자 협의)
- 셀 길이 제한: `db_cell_preview_chars` config 키 (기본 200)로 환경설정 편입
- 탐색기 버튼: `file_path` 컬럼명과 정확히 일치하는 셀에만 표시
- 탐색기 실행: 서버가 OS 네이티브 `explorer.exe` 실행 (브라우저 내부 레이어 아님), 파일 경로면 부모 디렉토리까지만

## 처리 단계
1. `server/configs.json`: `db_page_size`(20, "DB 관리 테이블 기본 출력 행 개수")·`db_cell_preview_chars`(200, "DB 관리 그리드 셀 출력 문자열 제한 길이") 시드 추가 → `seedConfigDefaults()` 누락 키 자동 INSERT → configs 테이블 + admin 환경설정 자동 노출.
2. `server/src/index.ts`: `POST /api/admin/fs/open-explorer` 신규 — `{path}` 존재 검증(미존재 404) → 파일이면 `dirname` 부모 디렉토리/디렉토리면 그대로 → win32 `explorer.exe <dir>`(비Win `xdg-open`) 실행, `windowsHide: true`, `FS_OPEN_EXPLORER` 관리자 활동 로그. `/api/admin/db/rows` size 미지정 기본값 50→20.
3. `server/src/services/dbManagerService.ts`: `fetchTableRows` 기본 size 50→20(최대 200 유지).
4. admin `ValuePreviewModal.tsx` 신규: 열릴 때 `window.innerHeight` 기준 `maxHeight = innerHeight - 120px`, 본문 `overflow-y: auto`, 닫기/backdrop/ESC, 헤더 글자수·줄수 표시.
5. admin `DbDataGrid.tsx` 재작성: `CellValue` 하위 컴포넌트 — `cellPreviewLimit`(기본 200) 초과 시 `…` 잘림 + `더보기` 링크, `col === "file_path"`이며 값 비어있지 않으면 `folder_open` 탐색기 버튼(진행 스피너/실패 시 하단 배너), `ValuePreviewModal` 연동.
6. admin `apiService.ts`: `openExplorerApi(path)` 추가.
7. admin `useDbManager.ts`: `selectTable(table, size = 20)` size 파라미터화(하드코딩 50 제거).
8. admin `DbBrowserPanel.tsx`: `dbPageSize`(기본 20)/`cellPreviewChars` props, `pageSize` 상태 초기값 = `dbPageSize`, 검색/페이지 이동 시 pageSize 전달, 페이지네이션에 행 수 드롭다운(20/50/100/200) 추가.
9. admin `SqlQueryPanel.tsx`/`DbManagerView.tsx`: `cellPreviewChars`/`dbPageSize` props 체인, `selectTable(table, dbPageSize)`.
10. admin `App.tsx`: `configs`에서 `db_page_size`/`db_cell_preview_chars` 파싱 → `<DbManagerView dbPageSize cellPreviewChars>`.
11. 문서: R-00203(configs 키·open-explorer API·rows 기본 20), R-00304(§3.1·§3.3 그리드 셀/탐색기 규정·체크리스트) 갱신.
