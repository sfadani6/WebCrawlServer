# 작업 이력: xvideos.com + xvideos.red 이중 도메인 지원 — "xvideos 페이징 액션" 화면 문구 + URL 분석 기반 경로 생성 (ask-20260811030252)

## 요청 (사용자 지시 원문)
- 액션 실행 문구가 `xvideos.com`만 표시되는데, **`xvideos.red`도 함께 지원**해야 한다.
- 실행 버튼 문구를 `best-of-red 자동 이동`이 아닌 **`[xvideos 페이징 액션]`**으로 변경할 것.
- URL이 `https://www.xvideos.com/best/2026-03`인데 베이스 경로가 `/best-of-red/2026-07`로 잡힘 → **URL을 분석**해 `best/2026-03`로 저장 디렉토리를 생성해야 한다. (하드코딩 기본값이 있는 듯함)
- `https://www.xvideos.red/` 도메인도 지원해야 한다.

## 확정 사항 (사용자 확인)
- ① 미디어 저장 시 `pageUrl`을 전달해 `images/<도메인>/<세그먼트>/<월>/<N>/`로 저장(기존 `images/common/...` 파일은 이동하지 않고 유지).
- ② 화면 문구만 변경하고, 내부 식별자(`COLLECT_BEST_OF_RED_*`, `useBestOfRedRunner`, `XvBestOfRed*`)는 전면 개명하지 않음.

## 처리 단계
1. `content.ts`(basic/opera): 범용 정규식 `XV_BEST_OF_RED_BASE_RE = /^(\/[^/]+\/\d{4}-\d{2})(?:\/(\d+))?\/?$/` + `isXvideosHost()` 도메인 가드(xvideos.com/xvideos.red, `www.` 허용) 도입. `parseXvBestOfRedUrl()`은 하드코딩 `best-of-red` 없이 현재 URL을 분석.
2. `offscreen.ts`(basic/opera) `handleFetchPageMediaBundles()`: `pathSegments`를 `[세그먼트, YYYY-MM, 페이지]`로 해석, `pathSegments[0]` → category로 분리, `pathSegments.slice(1)` → 저장 계층으로 전달. 번들에 `pageUrl` 포함. 하드코딩 `best-of-red` 중복 제거 로직 제거.
3. `chromeService.ts`/`useBestOfRedRunner.ts`(basic/opera): `requestFetchPageMediaBundles()` payload에 `pageUrl: string` 전달.
4. `usePopupState.ts`/`actionRunner.tsx`(basic/opera): 탭 탐색을 `["*://*.xvideos.com/*", "*://*.xvideos.red/*"]` 이중 도메인으로, 페이징 경로 정규식 `/\/(?:[^/]+)\/\d{4}-\d{2}/` 우선 매칭.
5. `BasicTab.tsx`(basic/opera): `SITE_IMAGE_BUTTONS`에 `"xvideos.red": ["normal", "info"]` 추가, 액션 카드 헤더 `xvideos.com · xvideos.red` + 버튼 라벨 `xvideos 페이징 액션` + 저장 경로 설명 갱신.
6. `ActionRunnerView.tsx`(basic/opera): 헤더 `액션 실행기 · xvideos 페이징 액션` + 저장 루트 표기 `images/<도메인>/<세그먼트>/<월>/<N>/`(`initInfo.basePath.replace(/^\//, "")`).
7. 타입 검증: `node node_modules/typescript/bin/tsc --noEmit -p ...` basic/opera 모두 통과.
8. 빌드: `npm run build --workspace=basic-plugin` / `--workspace=opera-plugin` 모두 56 모듈 성공.
9. ESLint: `node node_modules/eslint/bin/eslint.js ...` — 오류 2건은 기존 `xvideosManager.tsx` react-hooks 미정의(내 변경과 무관), 경고 4건은 기존 미사용 변수·함수. 내 변경 관련 신규 오류 없음.
10. 문서: R-00430 §5.5/§6(URL 기반 경로·도메인 가드·pageUrl), R-00420 §4.5(COLLECT_BEST_OF_RED_INIT/PAGE·FETCH_PAGE_MEDIA_BUNDLES 규격), R-00440 §2.4+체크리스트(문구/경로), R-00480 §3.1(시나리오), R-00208(계층 경로·분리 저장 예시) 갱신.

## 확인된 동작 규칙 (검증 대상)
- xvideos.com/xvideos.red 두 도메인에서 "xvideos 페이징 액션" 버튼이 활성화되고 액션 실행기 팝업이 열린다.
- `https://www.xvideos.com/best/2026-03`에서 베이스 경로가 `/best/2026-03`(기본값 없이 URL 분석)로 표시된다.
- 미디어/JSON 저장 경로가 `images/<도메인>/<세그먼트>/<월>/<N>/`로 이중 폴더 없이 생성된다(예: `images/xvideos.red/best/2026-03/1/`).
