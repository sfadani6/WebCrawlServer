## 상세 변경 내용

### 1. server/app.js
- **변경 전**: allowedOrigins 변수 정의 전 verifyClient에서 참조 (undefined). WS_TOKEN 기본값 하드코딩
- **변경 후**: allowedOrigins/WS_TOKEN verifyClient 위로 이동. ENV_VARS 배열로 환경변수 7개 검증
- **변경 이유**: WebSocket 차단 버그 수정, 보안 강화

### 2. server/logs/logRotator.js
- **변경 전**: 파일 없음. 서버 시작 시 require 실패로 크래시
- **변경 후**: 일자별 로그 파일 생성, 30일 보관 정책, DB 레코드 정리 기능 포함
- **변경 이유**: 서버 기동 불가 버그 수정, 로그 관리 인프라 구축

### 3. server/scheduler/cronParser.js
- **변경 전**: getNextTime()이 1분 후만 반환하는 단순 로직
- **변경 후**: parseField/parseCron/getNextTime 완전 구현. *, ,, -, / 특수문자 지원
- **변경 이유**: 스케줄러 정상 동작을 위한 정확한 cron 계산 필요

### 4. server/routes/adminDb.js
- **변경 전**: 테이블명 검증 없이 직접 문자열 연결
- **변경 후**: isValidTableName() 함수 추가, getTableColumns()에서 테이블명 검증
- **변경 이유**: SQL Injection 방지를 위한 화이트리스트 검증 강화

### 5. docs/rule/workflow-management.md
- **변경 전**: v1.1.0, ask.md 처리 결과 유지 방식, todo.md 상태 갱신 방식
- **변경 후**: v1.2.0, ask.md 비우기 규칙, todo.md 완료 항목 삭제 규칙, CHANGELOG/ 상세 기록 규칙 추가
- **변경 이유**: 사용자의 강제 작업 흐름 규정 반영
