 `docs/ask.md`의 요청에 따라 서버와 통신할 수 있는 브라우저 확장 프로그램을 `plugin/` 디렉토리에 구현했습니다.

## 구현된 파일 구성

| 파일 | 설명 |
|------|------|
| `manifest.json` | Manifest V3, Chrome/Firefox/Opera 호환 |
| `background.js` | WebSocket MCP 프로토콜, 스크립트 실행 엔진 |
| `contentScript.js` | DOM 조작, 데이터 수집 |
| `popup/popup.html` | 연결 상태, 명령 전송, 로그 |
| `options/options.html` | 서버 URL, WS_TOKEN, 연결 설정 |
| `icons/` | 16/48/128 SVG 아이콘 |
| `README.md` | 설치/설정/사용법 |

## 주요 기능

1. **MCP 프로토콜 통신**: 서버 WebSocket과 양방향 통신 (요청/응답, 스크립트, heartbeat, 이벤트)
2. **8개 표준 명령어**: open_browser, crawl_page, run_process, stop_process, send_message, log_event, monitor_status, manage_db
3. **12개 스크립트 스텝**: navigate, click, input, extract, scroll, waitFor, collectImages, download, condition, loop, setVariable, custom
4. **브라우저 자동화**: 탭 제어, DOM 조작, 페이지 정보 수집, 스크롤링 등
5. **관리자 페이지 연동**: 관리자 페이지에서 생성한 모듈의 스크립트를 플러그인이 수신하여 실행하고 결과 반환
6. **다중 브라우저 통제**: 여러 탭/브라우저 인스턴스의 프로세스 통제 가능

## 설치 방법

브라우저에서 `chrome://extensions` → 개발자 모드 → 압축 해제된 확장 프로그램 로드 → `plugin/` 디렉토리 선택 → 옵션 페이지에서 서버 URL/토큰 설정 후 연결
