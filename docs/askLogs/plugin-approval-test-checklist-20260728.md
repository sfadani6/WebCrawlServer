# 플러그인 승인/웹소켓 연결 테스트 체크리스트

## 목적
이 문서는 Opera 브라우저 확장 프로그램의 플러그인 승인 흐름과 승인 후 WebSocket 연결이 실제로 동작하는지 확인하기 위한 테스트 절차를 정리한 문서입니다.

## 전제 조건
- 서버가 실행 중이어야 합니다.
- 관리자 페이지가 열려 있어야 합니다.
- 확장 프로그램이 Opera에 설치되어 있고 최신 코드가 로드된 상태여야 합니다.

## 1. 서버 상태 확인
- [ ] http://localhost:9600/health 에 접속한다.
- [ ] 응답이 정상적으로 오면 서버가 실행 중임을 확인한다.

## 2. 확장 프로그램 재로드
- [ ] Opera 브라우저에서 확장 프로그램을 다시 로드한다.
- [ ] 이전 캐시된 코드가 남아 있지 않도록 한다.

## 3. 플러그인 연결 시도
- [ ] 확장 프로그램의 연결 버튼을 클릭한다.
- [ ] 콘솔에 아래 로그가 보이는지 확인한다.
  - [ ] “서버 접속 요청 전송 중…”
  - [ ] “접속 요청 접수됨 … 승인 대기 중…”
- [ ] 연결이 즉시 실패하지 않고 승인 대기 상태로 유지되는지 확인한다.

## 4. 관리자 페이지에서 승인 대기 요청 확인
- [ ] http://localhost:9600/plugins 에 접속한다.
- [ ] “승인 대기” 탭을 확인한다.
- [ ] 방금 생성된 플러그인 요청이 보이는지 확인한다.
- [ ] 요청이 없으면 서버/DB/인증 상태를 다시 확인한다.

## 5. 관리자 승인
- [ ] 승인 대기 요청의 “승인” 버튼을 클릭한다.
- [ ] 승인 후 관리자 화면에 토큰이 인라인으로 표시되는지 확인한다.
- [ ] 승인된 항목이 “연결된 플러그인” 탭으로 이동하는지 확인한다.

## 6. 플러그인 측 연결 확인
- [ ] 플러그인 콘솔에서 아래 로그를 확인한다.
  - [ ] “접속 승인됨! WebSocket 연결을 시도합니다.”
  - [ ] “WebSocket 연결 성공”
- [ ] 플러그인 상태가 연결됨으로 바뀌는지 확인한다.

## 7. 최종 검증
- [ ] 관리자 페이지의 “연결된 플러그인” 목록에 승인된 플러그인이 보이는지 확인한다.
- [ ] 플러그인과 서버 간 WebSocket 연결이 지속되는지 확인한다.
- [ ] 필요 시 연결 종료 후 재연결까지 반복해 본다.

## 예상 성공 기준
- 승인 요청이 관리자 페이지에 표시된다.
- 관리자가 승인하면 토큰이 발급된다.
- 플러그인이 승인된 토큰으로 WebSocket에 연결된다.
- 연결 상태가 유지된다.
