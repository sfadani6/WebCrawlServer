# 작업 이력: xvideos 다운로드 매니저 — 스크롤바·이미지 URL 주소 표시·항목별 프로그레스 바 (ask-20260810064441)

## 요청
- "플러그인에서 xvideos.com 미디어 목록 하게 되면 다운로드목록 창이 나오는데 스크롤 바가 없어. 스크롤 바가 생기게 해주고."
- "이미지 리스트가 안 보여."
- "그리고 하나씩 다운로드 진행되고 완료된다는 프로그래스 바도 있어야 되지 않겠어? 각 개체마다."
- 추가 설명: "이미지 리스트란 이미지 다운로드 받을 이미지 주소야. 이미지 썸네일을 미리 보는 건 아니야."

## 확정된 결괏값 (사용자 승인, 질문 dismiss 후 권장안 확정)
- 스크롤바: 목록 컨테이너에 커스텀 가시 스크롤바(`.manager-list-scroll`, thumb `#475569`) 적용.
- 이미지 리스트: 썸네일 미리보기가 아니라 **다운로드 대상 이미지 URL 주소 3종**(`image_url`/`sfw_image_url`/`preview_video_url`)을 항목별로 `break-all`+선택 복사 가능하게 표시.
- 프로그레스 바: 단계별 실제 %(오프스크린 진행 이벤트) — 시작 0% 쉬머 → 30/55/80/95% 갱신 → 완료/실패 100%.

## 처리 단계
1. `plugins/basic-plugin/src/offscreen.ts`: `broadcastFetchProgress(bundleId, progress)` 헬퍼 신설(`chrome.runtime.sendMessage` + `.catch()` 가드, 수신자 미연결 시 무시) → `handleFetchMediaBundle`에서 메인 인출 30 / 보조 55 / 프리뷰 80 / 서버 전송 95 단계마다 브로드캐스트.
2. `plugins/basic-plugin/src/types/index.ts`: `XvideosDownloadItem`에 `progress: number`(0~100) 추가, 신규 `FetchMediaBundleProgressPayload` 타입 정의.
3. `plugins/basic-plugin/src/hooks/useXvideosDownloadManager.ts`: 항목 생성 시 `progress: 0`, `chrome.runtime.onMessage` 리스너(FETCH_MEDIA_BUNDLE_PROGRESS 수신 시 bundleId 매칭 progress 갱신, 0~100 클램프), 진행 시작 시 progress 0 리셋, done/failed 시 progress 100 확정.
4. `plugins/basic-plugin/src/components/XvideosManagerView.tsx`: 목록 컨테이너에 `.manager-list-scroll` 클래스, `DownloadListItem`에 이미지 URL 3줄(라벨+break-all)과 항목별 프로그레스 바(진행 중 0%는 쉬머 인디케이터, 이후 실제 % 스카이 바, 완료 에메랄드 100, 실패 레드 100, 우측 % 숫자) 추가.
5. `plugins/basic-plugin/src/popup.css`: `.manager-list-scroll` 웹킷/파이어폭스 스크롤바(thumb `#475569`·hover `#64748b`, track `#0a0e17`) + `.progress-bar-indeterminate` 쉬머 애니메이션(`@keyframes manager-progress-shimmer`) 추가.
6. **opera-plugin 동기화**: `offscreen.ts`/`types/index.ts`/`useXvideosDownloadManager.ts`/`XvideosManagerView.tsx`/`popup.css` 5종 헤더 교체 복사.
7. **문서 마감**: R-00440 §2.3(URL 주소 표시·프로그레스 바·스크롤바), R-00420 §4.5(FETCH_MEDIA_BUNDLE_PROGRESS 규격)·§5, R-00430 §5.4·§6, askLog 신규, todo.md/history.md 반영.
