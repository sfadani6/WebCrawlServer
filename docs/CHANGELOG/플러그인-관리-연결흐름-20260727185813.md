# 플러그인 관리 연결 흐름 수정 - 20260727185813

## 변경 개요
`/plugins` 화면에 잘못 표시되던 채팅 UI를 제거하고, 브라우저 플러그인 승인 토큰 기반 연결 흐름과 연결 종료 처리를 보강하였다.

## 변경된 파일 목록
- `server/admin-ui/src/components/PluginsPage.jsx`
- `plugin/background.js`
- `plugin/options/options.js`
- `server/monitor/connectionManager.js`
- `server/routes/plugin.js`
- `server/routes/admin.js`

## 파일별 상세 변경 내용

### server/admin-ui/src/components/PluginsPage.jsx
- 연결 흐름과 무관한 고정 채팅 UI를 제거하였다.
- 채팅 UI에만 사용되던 상태값과 `handleLoginRequest` 함수를 제거하였다.
- 화면 하단에 남아 있던 `</write_to_file>` 문자열을 제거하였다.
- 플러그인 옵션 안내 문구를 자동 승인 폴링 및 수동 토큰 입력 흐름에 맞게 수정하였다.

### plugin/background.js
- 기본 WebSocket 토큰을 빈 값으로 변경하였다.
- 저장된 승인 토큰이 있으면 새 승인 요청을 만들지 않고 해당 토큰으로 WebSocket 연결을 시도하도록 수정하였다.
- 승인 상태 폴링에서 토큰을 받으면 확장 프로그램 설정에 저장하도록 수정하였다.
- 연결 종료 시 승인 폴링도 중지하고 연결 단계를 초기화하도록 수정하였다.
- 상태 조회 응답에 연결 단계와 승인 토큰 정보를 포함하도록 보강하였다.

### plugin/options/options.js
- 토큰 입력 필드의 기본값을 빈 값으로 변경하였다.

### server/monitor/connectionManager.js
- 플러그인 요청 ID 기준으로 활성 WebSocket 연결을 종료하는 `terminatePluginConnections` 함수를 추가하였다.

### server/routes/plugin.js
- 플러그인 연결 종료 API가 실제 WebSocket 연결 종료 개수를 반환하도록 수정하였다.

### server/routes/admin.js
- 관리자 플러그인 연결 종료 API가 실제 WebSocket 연결도 종료하고 종료 개수를 표준 응답 데이터로 반환하도록 수정하였다.

## 변경 이유
- 연결 기능과 무관한 채팅 UI가 `/plugins` 화면에 표시되어 사용자가 플러그인 승인 UI와 혼동할 수 있었다.
- 승인 토큰 수동 입력 후 연결을 눌렀을 때 저장 토큰을 사용하지 않으면 연결 대신 새 승인 요청이 반복될 수 있었다.
- DB 상태만 변경하는 연결 종료는 실제 WebSocket 세션과 관리자 UI 상태 불일치를 만들 수 있었다.
