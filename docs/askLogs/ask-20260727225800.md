## 1. 개요 및 주요 개선 사항

- **README.md 문서 어수선함 정리**:
  - 기존에 `시작하기` 및 `서버 관리 명령어` 하위에 중복되어 분산되어 있던 서버 실행 설명을 `서버 실행 및 프로세스 관리` 단일 섹션으로 깔끔하게 일원화.
  - 중복 선언되어 있던 `# 개발 철학` 및 기타 어수선한 구성을 제거하고 직관적인 표와 코드 블록으로 재구성.

- **서버 실행 및 PM2 프로세스 관리 세부 명령어 강화**:
  - `npm start`, `npm run dev` 외에 PM2 기반 환경별 실행(`npm run dev:pm2`, `npm run prod:pm2`) 체계적 정리.
  - PM2 단독 실행, 단독 재시작(`npx pm2 restart WebCrawlServer`), 단독 중지/삭제(`npx pm2 delete WebCrawlServer`), 실시간 대시보드(`npx pm2 monit`), 로그 감시(`npx pm2 logs`), 부팅 시 자동 구동(`npx pm2 save/startup`) 등 실무에 필요한 PM2 명령어를 명확히 명시.
  - Express 백엔드 포트 설정(`PORT=3000` 기본, `0.0.0.0` 바인딩) 및 Vite 관리자 UI 빌드(`npm run build`) 필수 절차 강조.
